# 🍽️ FoodBridge

**FoodBridge** is a web-based food donation platform that helps reduce food wastage by connecting food donors with NGOs and charitable organizations. The platform allows individuals, restaurants, hotels, caterers, and event organizers to donate surplus food, ensuring it reaches people in need instead of being wasted.

---

# 📌 Features

* User Registration & Login
* NGO Registration & Login
* Food Donation Submission
* View Available Food Donations
* Accept & Manage Donation Requests
* Food Pickup Details
* Secure Data Storage using SQLite
* Responsive User Interface

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/YourUsername/FoodBridge.git
```

```bash
cd FoodBridge
```

---

## 2. Create a Virtual Environment (Recommended)

### Windows

```bash
python -m venv venv
```

Activate the virtual environment:

```bash
venv\Scripts\activate
```

---

## 3. Install Dependencies

```bash
pip install -r requirements.txt
```

If you don't have a `requirements.txt` file, install Flask manually:

```bash
pip install flask
```

---

## 4. Run the Application

```bash
python app.py
```

The application will start on:

```text
http://127.0.0.1:5000
```

Open the above URL in your browser.
